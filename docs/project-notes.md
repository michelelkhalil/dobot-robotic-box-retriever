# Project Notes

## Project
**Box Retriever Using a Robot Arm — ELEE1144 Group Project**

The system uses a Dobot Magician robotic arm controlled through an Arduino UNO. Three push buttons correspond to three predefined wooden-block storage locations. The Arduino sends stored Dobot command frames to perform the required pickup, transfer and drop-off sequence.

## Development Challenges
- Limited laboratory time for final integration and testing.
- Only one push button was initially available, so two additional buttons had to be sourced.
- The homing command queue required troubleshooting.
- The team initially had difficulty connecting all three button inputs to ground before using a shared ground connection.

## Physical Layout
A placement sketch was produced to keep Blocks A, B and C, the Dobot and the drop-off area in repeatable positions. This helped match the physical setup to the programmed movement sequences.
